# Dope Services

An original, dark neon storefront demo for gaming tools and creator services. Built with vanilla HTML, CSS and JS and no external dependencies.

## Pages
`index.html` (Home), `shop.html`, `product.html?item=<slug>` (product template), `faq.html`, `about.html`, `contact.html` (demo form).

## Structure
```
assets/css/style.css
assets/js/main.js
assets/images/  (original SVG logo + product art)
```

## Run
Open `index.html` directly, or run `python3 -m http.server` and visit http://localhost:8000. Deploys as-is to any static host (Netlify, GitHub Pages).

Testimonials and product names are placeholders. Checkout and the contact form are non-functional.
