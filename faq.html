    Three things fix almost every case: turn your antivirus off (Windows Defender completely, including real-time protection and tamper protection), right-click the file and run it as administrator, and install the Visual C++ and DirectX runtimes.

    Still closing? Restart the PC first — a loader that was blocked once stays blocked until the next boot. The full list is under Downloads.

  • Do I need to disable my antivirus?

    Yes. Antivirus programs can block the loader and the spoofer, so turn your antivirus off before you run them. For Windows Defender, turn it off completely, including real-time protection and tamper protection: Windows Security → Virus & threat protection → Manage settings.

    Defender flags this kind of software by category, not because it found something.

  • Is the Rust cheat external or injected?

    External. It runs on its own kernel driver and hypervisor instead of injecting code into the game, which keeps it separate from the processes Rust anti-cheat watches.

    Yes. Virtualization must be switched on in the BIOS — this is the one product in our shop that needs it; most others do not.

    If the loader says VMX or SVM is not supported, turn off Virtual Machine Platform and Hypervisor Platform under Windows features, or run bcdedit /set hypervisorlaunchtype off as administrator, then restart.
