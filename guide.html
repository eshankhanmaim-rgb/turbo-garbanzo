2.Let Windows allow it

Windows Defender will flag the loader. That is normal — it does this with every cheat. Add an exclusion for the folder you saved it in.

  • Windows Security → Virus & threat protection
  • Manage settings → Add or remove exclusions
  • Add the folder with the loader

TipAdd the folder, not the file. The loader replaces itself when it updates.

3.Get your key from your email

It is in your inbox within seconds of the payment. Check spam if it is not there.

4.Run the loader and paste the key

Right-click the loader and choose Run as administrator. Paste the key when it asks, then leave the PC alone until it says loaded.

  • Right-click the loader → Run as administrator
  • Paste the key, confirm, then wait
  • A short freeze while it loads is normal — do not click anything

TipSet your keyboard to English (US or UK) first. On other layouts the loader reads some key characters wrong.

5.Start the game and inject

Launch the game in fullscreen, then hit inject in the loader. Cheats is ready.

TipThe menu opens with Insert, or Home on some builds. Give it up to a minute — it opens once the game has finished loading.
